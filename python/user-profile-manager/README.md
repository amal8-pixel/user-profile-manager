# user Profile Manager 🐍
My first Python project during my AI Engineering learning journey.
## Description
A simple command-line application that collects user information, validates inputs, saves data to a text file, and reads it back.

## Features
- User input collection
- Input validation
- Save user information
- Read saved information
- Basic exception handling

## Technologies
- Python

## How to Run
```bash
python main.py
```
## Learning Goals
Practice Python fundamentals, file handling, and    exception handling through a hands-on project.
